\# Amazon ML Challenge 2026



Team repository for the Amazon ML Challenge 2026.



\## Project Structure



\- `data/` - Dataset files

\- `notebooks/` - Jupyter / Google Colab notebooks

\- `src/` - Reusable Python scripts

\- `submissions/` - Final submission files

\- Matplotlib

\- Seaborn
